# branch-management Specification

## Purpose

分支感知与切换：让用户在会话头部一眼看到当前分支（排版与宿主一致），并能从同一处切换、创建、删除、重命名分支，失败原因可见。

## Requirements

### Requirement: 会话头部分支芯片与宿主排版一致

会话头部 SHALL 显示当前分支芯片（分支名、ahead/behind、变更数）；芯片的字体 MUST 继承宿主头部正文样式（不使用等宽字体），字号、字重、行高与相邻头部元素一致；不在 git 仓库时 MUST 不渲染。

#### Scenario: 字体与相邻元素一致
- **WHEN** 会话头部同时显示「PTC 模式」「N 个子智能体」与本插件分支芯片
- **THEN** 分支芯片的字体族、字号与行高与这些相邻元素一致，没有等宽字体的突兀感

#### Scenario: 非仓库不渲染
- **WHEN** 会话工作目录不是 git 仓库
- **THEN** 头部不出现分支芯片，也不占据布局空间

### Requirement: 芯片弹层提供分支切换

芯片弹层 SHALL 列出当前分支与可切换的本地分支（远端分支单独分组），点击某个分支 MUST 触发一次 `git checkout`；切换成功后 MUST 更新芯片与面板并给出成功反馈；切换失败（工作区脏、冲突、无权限）MUST 在弹层内显示 git 的错误摘要而不是静默失败。

#### Scenario: 成功切换分支
- **WHEN** 用户在工作区干净时点击另一个本地分支
- **THEN** HEAD 切换到该分支，芯片分支名与变更列表随之更新

#### Scenario: 工作区脏导致切换失败
- **WHEN** 存在未提交改动且 git 拒绝切换
- **THEN** 弹层内出现错误条，说明 git 报告的冲突文件或原因，HEAD 保持不变

### Requirement: 分支的创建、删除与重命名

面板 SHALL 支持创建分支（基于当前 HEAD）、删除分支与重命名分支；删除 MUST 需要显式确认，MUST 拒绝删除当前分支，未合并分支删除时 MUST 明确提示需要使用强制删除。

#### Scenario: 创建并切换到新分支
- **WHEN** 用户输入新分支名并确认创建
- **THEN** 仓库出现该分支且 HEAD 指向它，芯片显示新分支名

#### Scenario: 拒绝删除当前分支
- **WHEN** 用户尝试删除当前所在分支
- **THEN** 操作被拒绝并提示不能删除当前分支，仓库保持不变

#### Scenario: 删除未合并分支需要确认
- **WHEN** 用户删除一个尚未合并的分支
- **THEN** 界面提示该分支未合并，要求二次确认后才使用强制删除

### Requirement: 日志过滤与分支切换是两个独立动作

历史视图的分支下拉 SHALL 只改变日志的范围过滤，MUST NOT 改变 HEAD；切换分支 MUST 由独立的显式动作完成，并在成功后就地提示「已切换到 <分支>」。

#### Scenario: 过滤分支不改 HEAD
- **WHEN** 用户在历史视图下拉里选择另一个分支作为日志范围
- **THEN** 只显示该分支的提交，HEAD 与当前工作区分支保持不变

#### Scenario: 切换分支后提示
- **WHEN** 用户通过切换动作成功切到新分支
- **THEN** 界面显示「已切换到 <分支>」，历史与变更列表刷新
